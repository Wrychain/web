# Station

> A collective.

- Collection of users
- Collection of channels
- Users can categorize channels available via the station

# Category

> Users form their own perspectives.

- Category is a named collection of channels.

# Channel

> Messages through time.

- A collection of users who can read the contents of the channel
- A collection of users who can write contents to the channel

# User

> The pivot.

# Message

> An utterance in a channel.

- Attachments (file pointer)
- Reactions
- Receipts
- Replies (self-referential)
